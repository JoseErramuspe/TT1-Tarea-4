# RespTarea 4

## Resp Parte 1
La diferencia entre descargar un proyecto como zip y clonarlo con Git es que el zip descarga solo los archivos, y git clone descarga también el historial de versiones y permite sincronizar cambios con Github.

## Resp Parte 2
El archivo README.md sirve para documentar el proyecto, explicar su funcionamiento, y como se usa.

## Resp Parte 3
Al ejecutar git status aparece la carpeta Estudiantes como untracked porque tiene archivos nuevos que todavía no los había agregado con el comando git add.

## Resp Parte 4
Un commit guarda una instantánea de los cambios realizados en el proyecto y te guardar un historial de versiones.
